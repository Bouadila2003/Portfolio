# Wafae Bouadila — Portfolio

Personal portfolio of **Wafae Bouadila**, full-stack web developer (Laravel & React) based in Agadir, Morocco.

- Bilingual (FR / EN), responsive and animated
- Built with **React 18 + Vite**, plain CSS
- Deployed on **Vercel**

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Content (skills, projects, experience, translations) lives in `src/data.js`.
